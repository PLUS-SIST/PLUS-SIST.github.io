# PLUS Group Website

Official website for the PLUS (Perception, Learning and Understanding Systems) research group at ShanghaiTech University.

🌐 **Website**: https://plus-sist.github.io/

## Quick Start

Visit our website to learn more about:
- Our research team and members
- Latest publications and news
- Research topics and projects
- How to join our group

## For Developers

This website is built with [Hugo](https://gohugo.io/) using the Academic theme.

### Local Development

See detailed instructions in `plus_website-master/README.md`

```bash
cd plus_website-master
bash view.sh
# Visit http://localhost:1313
```

### Deployment

The website is automatically deployed to GitHub Pages via GitHub Actions when you push to the `main` branch.

See `DEPLOY_GUIDE.md` for detailed deployment instructions.

## Repository Structure

- `plus_website-master/` - Hugo website source code
- `.github/workflows/` - GitHub Actions for automatic deployment
- `DEPLOY_GUIDE.md` - Detailed deployment guide
