## Introduction
We address the problem of joint detection and segmentation of multiple object instances in an image, which is a key step towards scene understanding. In particular, we aim to reduce the annotation cost and integrate prior knowledge into data-driven methods. We have proposed several active inference and efficient learning strategies, including weakly supervised semantic segmentation, dynamic model estimation, semi-supervised learning and exemplar-based approach to the task of instance segmentation。
